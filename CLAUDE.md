## Hard rules

- **Read-only toward the save.** `TryGetByGuid`, never `FindOrCreate`; requirement evaluation is an
  allowlist of verified-pure checks. Read [docs/GOTCHAS.md](docs/GOTCHAS.md) before touching
  `Requirements.cs` or `GrowthReader.cs`.
- **`GameFonts.cs` / `GamePalette.cs` / `PanelSprite.cs` are vendored VERBATIM from ChestLabels** — do
  not diverge them here; fix bugs in both copies.
- **`pack.ps1` and `Directory.Build.props` are workspace-synced canonicals** — regenerated by
  `../../tools/sync-mod-files.ps1`; don't hand-edit them here.
- **Version** lives only in `src/PlantPeek.csproj` `<Version>`; bump only when publishing. Never hardcode
  it in `Plugin.cs`.
- **Commit identity:** `dirtyredz <dirtyredz@live.com>`.

## Build

```bash
dotnet build "src/PlantPeek.csproj" -p:SkipDeploy=true
```

Auto-deploys to the game's BepInEx plugins folder without `SkipDeploy`. `MSB3277` warnings are benign
(referencing the whole game `Managed` folder). Pack a release with `.\pack.ps1`.

## Structure-review gate
